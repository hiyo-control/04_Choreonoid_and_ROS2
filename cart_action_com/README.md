# Cart Action communication
## How to build program
1. Open terminal at "./ros2_ws" folder
2. Execute "colcon build --packages-select cart_action_com"

## How to execute
1. Open terminal at "./ros2_ws"
2. Execute "source ./install/setup.bash"
3. Execute "ros2 run cart_action_com cart_action_client"
